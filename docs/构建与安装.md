# 构建与安装（无付费开发者账号）

> 目标：不花 $99，把 CarNovel 装到自己 iPhone 上。
> 结论：**能装，但「编译」和「安装」是两件事，各自有门槛。**

---

## 一、先厘清两个概念（很多人在这里想错）

| | 需要什么 | 免费方案 |
|---|---|---|
| **编译**（把 Swift 变成 .ipa） | **Xcode，而 Xcode 只有 macOS 有** | Mac / 云 Mac / GitHub Actions macOS runner |
| **安装**（把 .ipa 装进 iPhone） | 签名工具 + **免费 Apple ID 即可** | SideStore / AltStore / Sideloadly |

**侧载只解决「安装」，不解决「编译」。** 你还是得先有一台能跑 Xcode 的机器产出 .ipa。

---

## 二、但有个好消息：这套设计天生适合侧载

因为我们**刻意不申请 CarPlay 权限**：

- 不需要等 Apple 审批（entitlement 申请要几个月）
- 不需要签 CarPlay Entitlement Addendum
- 免费 Apple ID 的 entitlement 白名单限制里，我们只用到 `UIBackgroundModes: audio`（本来就允许）
- IPA 干净，侧载工具不会因为缺少受限 entitlement 而签名失败

**如果当初选了「申请 CarPlay 权限」那条路，免费账号根本走不通** —— 这是这个设计决策的额外收益。

---

## 三、免费 Apple ID 的硬限制（所有侧载工具都一样）

任何工具都绕不过这三条，因为限制来自 Apple Developer 免费账号本身：

| 限制 | 值 |
|---|---|
| **签名有效期** | **7 天**，过期后 App 打不开，要续签 |
| **同时安装的侧载 App 数** | **3 个**（含侧载工具自身） |
| **每 7 天可注册的 App ID 数** | **10 个** |

**7 天续签这一条要重点考虑。** 你这个场景是「开车时用」，如果 App 恰好在你出门前过期打不开，会很扫兴。

> 3 个 App 名额里，SideStore 自己占一个。也就是说你实际只能装 2 个自己的 App。
> 想多装可以用 **LiveContainer** —— 它在一个名额里嵌套跑多个 App。

---

## 四、三个工具怎么选

| | Sideloadly | AltStore | **SideStore** |
|---|---|---|---|
| 形态 | 桌面程序 | 手机端 App + 电脑端 AltServer | AltStore 的分支 |
| **需要电脑的时机** | **每次安装都要** | 首次设置 + **每次续签都要同一 WiFi 有电脑** | **只有首次设置** |
| 续签方式 | 电脑后台守护进程 | 经 AltServer 走 WiFi | **设备端自签**（靠本地 VPN） |
| 能否改 IPA | ✅ 可注入 dylib/deb | ❌ | ❌ |

### 推荐：**SideStore**

一次电脑设置之后，**续签完全在手机上完成**（通过 LocalDevVPN 这类本地 VPN 模拟本地网络）。
对你「用 Windows、不想老连电脑」的情况最合适。

代价是多几个活动部件 —— pairing 文件会在 iOS 更新或设备重置后失效，
VPN 有时后台掉线。社区里「You are not signed in」这类问题基本都和它有关。

**注意**：SideStore 官方文档称支持到 iOS 26.x，但**每次 iOS 点版本更新都可能暂时打断**（26.4、26.5 就打断过一批人）。
建议：装好之后**先关掉自动更新**，确认能稳定续签再说。

### 备选

- **AltStore**：最稳定成熟，但续签要电脑常开在同一 WiFi。家里有台常开的机器就用它。
- **Sideloadly**：你需要自己改 IPA 时才用（比如注入 tweak）。除此外电脑依赖太重。
- **证书类服务**（Signulous / builds.io 等）：跳过 7 天限制，但**企业证书会被 Apple 批量吊销**，说停就停，而且来路不明有隐私风险。**不建议**。

## 五、具体流程

### 第 1 步：拿到 .ipa（免费）

**Windows 上的免费路径是 GitHub Actions。**

```
Windows 写代码 → push 到 GitHub
    → GitHub Actions 的 macOS runner 用 xcodebuild 编译
    → 产出 .ipa 作为 artifact 下载
```

要点：
- runner 镜像选 **macos-26**（2026 年 4 月起 App Store Connect 上传要求 Xcode 26+，本地构建也建议对齐）
- 免费账号用 **development 证书 + ad-hoc 签名**即可，不需要 App Store 分发
- 私钥 / 描述文件放 **GitHub Secrets**，不要提交进仓库

**注意 GitHub Actions 免费额度**：公开仓库免费，私有仓库每月 2000 分钟，macOS runner 按 **10 倍**计费 ——
也就是说实际只有 **200 分钟/月**的 macOS 构建时间。一次完整 iOS 构建大概 5–10 分钟，够用但别乱触发。

其他免费路径：
- 借一台 Mac（最省心）
- 云 Mac 试用（MacinCloud 等，通常要付费，约 $20/月起）

### 第 2 步：装 SideStore

需要一次电脑操作（Windows 也行）：

1. 手机上装 **LocalDevVPN**
2. iPhone 用 USB 连电脑，解锁并「信任此电脑」
3. 打开 SideStore 的官方安装器（文档里叫 iloader），用**免费 Apple ID** 登录
4. 选设备 → 安装 SideStore（Stable）
5. 手机上：设置 → 通用 → VPN 与设备管理 → 信任开发者
6. **iOS 16+ 需要额外开启**：设置 → 隐私与安全性 → **开发者模式**
7. 打开 LocalDevVPN 连接
8. 打开 SideStore，用同一个 Apple ID 登录
9. My Apps 里点 SideStore 旁边的 **7 DAYS** 计数器做一次续签

> ⚠️ Apple ID 密码会经过这个工具。**只从官方渠道下载**，别用名字像的山寨版。

### 第 3 步：装 CarNovel

1. 用 SideStore 导入上一步拿到的 .ipa
2. 手机信任开发者证书
3. 打开 App → 点 AirPlay 按钮 → 选车机

### 第 4 步：往里放页面文件（不用重编译）

`Info.plist` 里已经开了 `UIFileSharingEnabled`，所以：

**Finder / iTunes → 文件共享 → 选 CarNovel → 拖入 mp4 文件**

文件名按 `ch01_p001.mp4` … `ch01_p018.mp4` 命名，App 会按名排序当页序。

这样你在 7 天周期内可以随意换小说内容，**不需要重新构建、不需要重新签名**。

## 六、要不要干脆上付费账号

**$99/年 / 约 ¥688** 换来的东西：

| | 免费账号 | 付费账号 |
|---|---|---|
| 签名有效期 | 7 天 | **1 年** |
| 同时安装 App 数 | 3 | 不受限 |
| 侧载工具续签负担 | 每周一次 | 基本不用管 |
| 能否用 TestFlight | ❌ | ✅ |

**判断标准：**

- 如果你只想**先验证这个方案能不能用** → 免费侧载完全够，先跑通再说
- 如果确认要**长期天天用**（车里阅读器是个日常工具）→ 那 $99 买到的是「不用每周操心续签」，对一个真正常用的东西是值的

我的建议：**先用免费方案把 App 跑起来验证**，确认好用再决定要不要付费。
不要一开始就为了工具链花钱。

## 七、安全提醒

- **别用来路不明的证书服务**：企业证书会被 Apple 批量吊销，且这些服务会碰你的 Apple ID
- **只从官方渠道下载侧载工具**：网上大量山寨 AltStore / SideStore 站点会窃取 Apple ID
- **某些"一键安装"网站是骗局**：声称支持 iOS 11 到 26 全版本、全机型的，技术上不可能存在，
  实际是在套问卷返利。别碰
- 免费账号的 Apple ID **建议用备用账号**，不要用你的主 Apple ID

---

## 八、一句话总结

**能走侧载。** 路径是：

```
Windows 写码 → GitHub Actions(免费 macOS) 编译出 .ipa
             → SideStore(免费 Apple ID) 装进手机
             → 每周续签一次
```

唯一要接受的不便是 **7 天续签**。如果觉得烦，再考虑 $99/年。
